# Change Log:

## 1.0.0

- First version: `WebBrowserSession` (start or reuse a Chrome, Edge, Brave or Chromium window with a persistent profile and control it through the DevTools protocol), `WebBrowserScreen` (page streamed into a texture, mouse and keyboard forwarding, JavaScript bridge, game-made HTML), `WebBrowserView` with uGUI and 3D-surface input components for scenes, a docked `WebBrowserWindow` in the Editor, and `DownloadAsync` for files behind a sign-in.
